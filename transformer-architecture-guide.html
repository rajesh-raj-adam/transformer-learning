Every matrix a token becomes, traced end to end.

The transformer turns words into vectors, vectors into attention, and attention into meaning — one matrix multiplication at a time. This guide walks the full pipeline: tokenizer to logits, with live, computed animations at every stage.

Stage 01

Tokenization: text stops being text

A transformer never sees words. It sees integers, chosen from a fixed vocabulary of 30,000–100,000+ subword pieces learned by an algorithm like Byte-Pair Encoding (BPE) or SentencePiece. Common words stay whole; rare ones get split into familiar fragments — which is how the model handles words it has never seen.

Each token chip above maps to one row in a giant lookup table — the embedding matrix — which is where Stage 02 begins.
Stage 02

Embeddings: an integer becomes a point in space

Every token ID indexes into a learned embedding matrix of shape vocab_size × d_model. The row it retrieves is a dense vector — typically 512 to 12,288 numbers — that encodes learned meaning. Similar words land near each other in this high-dimensional space.

Toy embedding vectors (d = 12, real dims are 100s–1000s)
What the vector encodes

No single dimension has a clean human label, but directions in this space correspond to learned regularities — famously, king − man + woman ≈ queen. The model discovers this geometry entirely from data; nobody hand-designs it.

Dimensionality is a budget: more dimensions can encode more distinctions, at the cost of more compute and parameters. GPT-3's largest variant used d_model = 12,288.

Stage 03

Positional encoding: giving order to a bag of vectors

Self-attention on its own is order-blind — it treats a sequence like a set. The original "Attention Is All You Need" architecture fixes this by adding a deterministic wave pattern to each embedding, so position 0 and position 50 get distinguishably different signatures.

PE(pos, 2i)  = sin( pos / 10000^(2i/d_model) )
PE(pos, 2i+1) = cos( pos / 10000^(2i/d_model) )
Sine/cosine waves across positions, by dimension
The resulting encoding matrix (position × dimension)

Low dimensions oscillate fast (fine-grained position), high dimensions oscillate slow (coarse position) — together they act like a binary clock made of waves. Modern models (GPT-NeoX, LLaMA, Qwen) mostly use Rotary Positional Embeddings (RoPE) instead, which rotates Q/K vectors by an angle proportional to position rather than adding a fixed vector — better extrapolation to longer sequences.

Stage 04 · the core mechanism

Self-attention: every token asks, every token answers

Each token's embedding is projected through three learned weight matrices into a Query, a Key, and a Value vector. A token's Query is compared against every other token's Key to produce attention scores — how much that token should "listen to" every other token.

Attention(Q, K, V) = softmax( QKT / √dk ) · V

The √d_k scale matters more than it looks: without it, dot products grow with dimensionality, softmax saturates toward one-hot, and gradients vanish. It's a numerical-stability fix, not a conceptual one.
Stage 05

Multi-head attention: several relationships at once

One attention pattern can only capture one kind of relationship well. So d_model is split into h parallel heads, each with its own Q/K/V projections operating on a lower-dimensional slice — one head might track syntax (subject → verb), another coreference (pronoun → noun), another local adjacency.

MultiHead(Q,K,V) = Concat(head₁, …, head_h) · WO
where headi = Attention(QWiQ, KWiK, VWiV)

Each small heatmap above is a genuine, independently-computed attention pattern for the sentence "the cat sat on mat" — same tokens, different learned projection per head, so each head lights up differently. In production models (h = 12 for GPT-2, up to 128 for the largest LLMs) heads are concatenated and passed through one final linear layer, WO, to mix information back together.

Stage 06

Residual connections & layer normalization

The residual stream

Every sub-layer's output is added back to its input: x + Sublayer(x). This "residual stream" is the backbone the whole network reads from and writes to — it's what lets gradients flow cleanly through 96+ stacked layers without vanishing, and lets any layer skip its transformation entirely if it has nothing useful to add.

LayerNorm

Before (pre-norm, modern) or after (post-norm, original paper) each sub-layer, activations are normalized to zero mean and unit variance per token, then rescaled by learned gain/bias. This keeps activation magnitudes stable as depth grows — without it, deep stacks are close to untrainable.

Stage 07

The feed-forward network: per-token reasoning

After attention mixes information across tokens, the feed-forward network processes each token position independently — the same two-layer MLP is applied identically at every position. This is where most of a transformer's parameters actually live.

FFN(x) = W₂ · activation(W₁x + b₁) + b₂   // hidden dim ≈ 4×d_model, activation: GELU / SwiGLU

The expand-then-contract shape (d_model → 4×d_model → d_model) gives the network room to compute richer intermediate features before compressing back down. Recent models (LLaMA, PaLM) swap GELU for gated variants like SwiGLU, trading one weight matrix for three but improving quality per parameter.

Stage 08

Stacking it: encoder, decoder, or both

A single attention + FFN block is one layer. Real models stack N of them (6 in the original paper, 96 in GPT-3, 120 in GPT-4-class models), each with its own weights, each refining the residual stream a little further.

Most modern LLMs (GPT-4, Claude, LLaMA, Gemini) are decoder-only: one stack, causal masking, trained to predict the next token. It turned out to be a remarkably general recipe.

Stage 09

Causal masking & cross-attention

Causal mask

A decoder must never let token 3 peek at token 5 — that would be cheating at next-token prediction. Before softmax, illegal positions are set to −∞, so they collapse to exactly 0 after softmax. The result is the lower-triangular pattern below.

rows = query position · columns = key position

Cross-attention

In encoder–decoder models, one extra attention layer lets the decoder query the encoder's output: Queries come from the decoder's current state, but Keys and Values come from the encoder. This is literally how a translation model looks back at the source sentence while writing the target one.

Stage 10

From final vector to next word

After the last layer, each position's vector is projected by a linear layer back up to vocabulary size, then softmax turns those logits into a probability distribution over every possible next token.

Predicting the next token after "The cat sat on the ___"
Greedy

Always pick the single highest-probability token. Deterministic, but repetitive and dull over long generations.

Top-k / Top-p sampling

Sample from only the top k tokens, or the smallest set whose cumulative probability exceeds p. Balances coherence and variety.

Temperature

Divides logits before softmax. Low temperature sharpens the distribution (safer); high temperature flattens it (more creative, riskier).
